About This Periodic Table

This web application is a state-of-the-art interactive periodic table of chemical elements designed with a modern glassmorphism aesthetic, smooth transitions, and comprehensive scientific data for all 118 elements.

Key Features

  • All 118 Elements: Every element from Hydrogen (1) to Oganesson (118) with accurate IUPAC data.
  • Interactive Bohr Atom Simulator: Real-time animated canvas modeling actual electron shell distributions.
  • Real-World Specimens: High-resolution real-world photos and authentic specimens from Wikimedia Commons with dynamic visual fallbacks.
  • Temperature Simulation Slider: Dynamically change temperature from 0 K to 6000 K to observe state changes (solid → liquid → gas).
  • Property Heatmaps: Color code the table by electronegativity, density, melting/boiling points, or atomic mass.
  • Instant Search & Filter: Filter by category, block (s, p, d, f), or search by name, symbol, or atomic number.
  • Keyboard Navigation: Navigate tiles with arrow keys, press Enter to view details, and press Esc to close.
  • Cosmic Chemistry Lab: Compare elements, explore property trends, save favorites locally, follow historical use-case context, and play a data-driven chemistry challenge.
  • GitHub Pages Ready: Built purely with standard client-side technologies (zero build steps, pure static HTML/CSS/JS).
